# Sum up 24 November's world news in one image

Entry program for the make.fun bounty "Sum up 24 November's world news in one image".

Run `python3 main.py` (Python 3, standard library only, no network) — it deterministically writes `./entry.png` (1024x1024 PNG): 40 Reuters stories from 24 Nov 2026 in one newspaper-style image.
